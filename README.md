# Каталог книг

На данном веб-ресурсе пользователь может ознакомиться с каталогом книг, имеющихся в библиотеке ВУЗа. Для удобства нахождения той или иной книги на сайте представлена функция поиска по названию, реализована возможность создавать новые книги, редактировать и удалять уже имеющиеся. Сайт также оснащён чатом для любителей книг, в который может зайти любой пользователь, введя никнейм.

## Описание

Целью данной работы являлось освоение принципов работы с API-сервисом: написание клиента для взаимодействия с API, осуществляющего GET, POST, PUT и DELETE методы HTTP-запросов, написание типов для лежащих на сервере данных для корректного взаимодействия с ними в коде, осуществление их отображения на странице. Также были закреплены навыки работы с библиотеками axios и socketIO.

## Требования 

- Пакетный менеджер npm
- Axios v1.13.4
- React v19.2.0
- React-dom v19.2.0
- React-hook-form v7.73.1
- Socket.io-client v4.8.3

## Установка
Для того, чтобы запустить проект на своём вычислительном устройстве необходимо: 
1. Клонировать репозиторий на устройство
2. Установить зависимости с помощью следующей команды в консоли, находясь в корне проекта:
```bash
npm install
```
3. Запустить локальный сервер:
```bash
npm run dev
```
4. Проект готов к использованию по ссылке, выведенной в консоль
